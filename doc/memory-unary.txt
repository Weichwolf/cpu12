Native byte memory unary operations

Indexed 60..69/E7 and extended 70..79/F7 cover NEG, COM, INC, DEC, LSR,
ROL, ROR, ASR, ASL, CLR and TST. Indexed operations use all 256 documented
postbytes, including indirect pointers and automatic X/Y/SP changes.
The primary S12CPUV2 instruction entries are pinned in reference-manifest.json.

CLR writes zero without reading the old operand. TST reads once and never
writes. Other operations resolve the address, read the actual byte, compute
and write the result, then publish flags, any index change and the next PC.
Indirect pointer reads precede operand accesses; pointer/operand aliasing does
not cause pointer re-fetch. Flags use CPU12 rules, including shift V=N xor C,
COM setting C, INC/DEC retaining C, and unchanged H/upper CCR bits.

Known RAM uses native host operations without runtime instruction helpers.
Partial RAM admission happens once before a read/modify/write sequence; the
result flags survive the native byte store. CLR/TST use one actual data access.
Only external accesses call the supplied bus. That path retains target,
result, candidate CCR and bus context in a 16-byte native frame across real
callbacks.
Callbacks observe original unretired CPU state; accepted completion publishes
CPU changes. A refused pointer/read/write reports exact address, width, value,
PC and opcode, leaves CPU state unchanged and latches the fault against replay.
Actual callback effects remain, including a write whose owner returns failure.
This instruction API contract does not model hardware bus-cycle timing.

The independent mathematical model covers all byte operands and CCRs in full
and partial RAM. Directed indexed/auto, pointer alias, wrapping address, real
callback clobbers, phase refusals and missing CLR-read/TST-write handlers check
the access contract. No manufacturer program is embedded in these tests.
The 1538224 memory-unary cases and all ten earlier component consumers passed
on one coherent optimized library; memory-unary-reference.json pins current
sources, binaries, actual terminal exits and logs.
Remaining ISA, reset/IRQ/waits, fetch/native regions, checkpoints, event budgets
and Blofeld integration still require implementation. Component correctness
is not evidence of complete instrument operation or real-time throughput.

  cmake --build --preset release --target cpu12-memory-unary-test
