Native counter and loop branches

Opcode 04 implements DBEQ/DBNE, IBEQ/IBNE and TBEQ/TBNE with counters
A, B, D, X, Y and SP. Decrement/increment wraps at the counter's actual
8-/16-bit width, then the zero/nonzero decision uses that result. Test forms
leave the counter unchanged. Every form preserves every guest CCR bit;
branch decisions never depend on the incoming guest Z flag.

A signed nine-bit displacement is relative to the next instruction, PC+3.
Postbyte bit 4 supplies the sign; bit 3 is ignored. This follows the literal
encoding tables and Table A-6 in the pinned S12CPUV2 manual. Some IBEQ/IBNE
prose footnotes incorrectly call bit 0 the sign; their own code tables use
bit 4. The 144 normal postbytes include both bit 3 aliases; 112 undocumented
combinations (selectors 2/3 or operation 3) fail without retirement.

Generated code directly modifies or compares the selected byte/word register,
branches on native ZF and advances the actual live guest PC. It does not call
an ISA helper, access guest memory or touch guest flags. All decoder and host
template selection happens on a native-cache miss. Complete raw captures keep
ignored-bit aliases distinct in the cache.

Independent arithmetic expectations cover every byte value/CCR and every word
value at directed CCRs. All 512 signed displacements, all counter forms,
wrapping PC boundaries, unchanged nonselected registers/CCR, ignored-bit aliases,
malformed captures and undocumented postbytes are checked. An authored DBNE
sequence repeats one cached entry until the live counter reaches zero.
No manufacturer application program is used. The 15289347 loop cases and all
eleven previous component consumers passed on one coherent optimized library.
loop-reference.json pins sources, binaries, actual terminal exits and logs.
This family does not establish full CPU12 operation,
interrupt timing, Blofeld firmware boot or real-time instrument performance.
