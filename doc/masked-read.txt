Selected-bit byte reads

BRSET/BRCLR request only their operand mask through optional Io.read_masked.
MaskedByteRead carries address16 and mask8. Unselected returned bits convey
no knowledge; the runtime clears them before the native branch decision.
Known ordinary RAM retains its direct native path without an owner call.

If read_masked is absent, one actual Io.read performs a full byte read before
masking. The full-byte provider must establish all bits. A rejecting selected
provider never triggers a second/full read. Missing or rejecting providers
fault visibly without retirement or CPU/index changes. Mask00 still performs
a real read, including destructive effects; its value-independent decision
does not authorize skipping the bus operation.

RunResult.read_mask records requested bits on byte read/fetch faults, including
00; ordinary byte/fetch failures useff. Other outcomes use0. Failure payloads
retain the actual callback diagnostic byte, including unselected bits; those
diagnostic bits are not accepted CPU data or claims of GPIO bit knowledge.
The same native fault latch prevents replay after cache invalidation.

Ordinary loads, words and read-modify-write operations keep their existing
interfaces. BSET/BCLR need the full old byte to preserve unselected bits and
compute N/Z/V correctly. A selected provider cannot replace that knowledge.
Only external bit-branch reads use the new real-I/O helper; generated RAM
execution receives no additional helper or mask dispatch.

Focused reproduction:

  cmake --preset release
  cmake --build --preset release --target cpu12-masked-read-test
  ctest --test-dir build/release --output-on-failure -R '^masked-read$'
