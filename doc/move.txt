Native HCS12 memory transfers

MOVB/MOVW implement all six immediate/extended/indexed source/destination
combinations. The source value is captured before writing the destination;
word accesses are big-endian and wrap at ffff-to-zero. No CCR bit changes.
Indexed operands allow 236 single-postbyte forms: signed five-bit constants,
unsigned A/B/D offsets and automatic X/Y/SP changes. Nine-/sixteen-bit
extensions and all indirect forms fail before data access.

Operands follow source-language source/destination order even where encoding
places the destination postbyte before the source address or immediate.
Resolve/read the source, logically apply its index change, then resolve the
destination using that updated base. Both automatic changes accumulate when
the same register is used. An accepted destination write publishes the final
index updates and next PC. Source or destination refusal preserves the entire
original CPU state, reports the exact phase/address/value/width and latches
against replay; actual read or partial write effects remain.

Legal destination address calculation needs no bus call and retains the
captured value in a host register. Generated MOV therefore requires no host
frame, including external source and destination accesses. Known RAM is read
and written natively; only actual external accesses call the supplied owner.
A word crossing a partial RAM boundary uses the real logical wide callback
for the complete word, never guessed byte transactions or fabricated cells.

This implementation uses documented HCS12 next-instruction PC semantics,
matching the integrating emulator's inferred MC9S12UF32 model. The original
M68HC12 move-queue corrections in S12CPUV2 Table 3-3 differ and are not
implemented. This distinction is an explicit library compatibility limit,
not a hardware-measured identification of the physical Blofeld MCU.

An independent authored SLEIGH observation has 45318 cases: 45312 source-auto
MOVB/MOVW cases against every allowed destination (12864 shared-base cases)
and six literal next-PC examples. Actual source reads precede destination
writes, original source values survive overlap, and full final registers agree
with sequential source/destination expectations. This corroborates the manual
model; the reference implementation is not treated as measured silicon.

Independent JIT tests enumerate byte/word data and CCR domains, all 236x236
indexed pairs, distinct single-indexed instruction lengths, partial RAM,
wrapping/overlapping words and precise external phase effects. No manufacturer
program is embedded. The 2306650 current MOV cases and all thirteen previous
component consumers passed on one coherent optimized library.
move-reference.json pins current sources, actual binaries, terminal exits and
logs; the separate reference observations retain their own source/specification
hashes.
Remaining ISA, reset/IRQ/waits, fetch/native regions, checkpoints, cycle budgets
and Blofeld integration still require work. Component results do not establish
firmware boot, complete instrument operation or real-time throughput.
