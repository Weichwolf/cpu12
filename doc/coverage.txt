CPU12 coverage — incomplete

Current public API: Core(Memory, Io*, Options), run_instruction(captured_bytes),
step(), run(instruction_budget), reset(vector), interrupt_ready(kind) and
interrupt(request), state(), resume_from_stop(), checkpoint() and restore().
Borrowed byte views provide
unified/window/external layouts; native cache bounds are checked at construction.
Fetched execution uses explicit code transport. The board owns clocks, source
arbitration and acknowledgement; native interrupt events retire no instruction.

Initial native implementation on x86-64/Linux:
- Logical byte fetching from current RAM or explicit Io.fetch, separate from data.
- Bounded instruction sequences, precise fetched faults, address wrapping and
  byte/length cache keys for changed code; no physical prefetch/timing claim.
- Actual reset-vector reads and S/X/I forcing, with explicit retention policy
  for other CPU state; peripheral/clock/storage reset belongs to the board.
- Native IRQ/XIRQ vector and nine-byte stack entry, mask eligibility, and the
  following-instruction recognition delay for ANDCC/TAP transitions.
- Native RTI restores CCR/B:A/X/PC/Y, wraps SP, and cannot raise a clear X mask.
- Native WAI/STOP save the actual following PC and enter explicit idle states;
  disabled STOP advances without stopping. Idle execution performs no fetch.
- Instruction budgets exit at a real wait boundary without a fault or fabricated
  retirement. Eligible wake reuses the genuine saved frame without duplicate writes.
- Explicit masked-XIRQ STOP continuation adjusts SP/state natively without vector
  service, stack reads, flag changes or instruction retirement.
- CPU checkpoints retain registers, idle state, IRQ delay and all fault metadata;
  active or invalid replacement refuses before mutation. Bus/board state is external.
- External entry/return stages CPU publication and retains actual partial effects
  on faults without automatic replay. Full known RAM uses no host frame/callback.
- Optional selected-bit byte reads for BRSET/BRCLR preserve real read effects,
  including mask00; ordinary loads, words and RMW still require complete data.
- Captured NOP.
- Immediate LDAA/B, ADDA/B, SUBA/B, CMPA/B, ANDA/B, ORAA/B, EORA/B, BITA/B.
- ADCA/B and SBCA/B in immediate/direct/extended/all existing indexed forms.
- Inherent A/B NEG/COM/INC/DEC/LSR/ROL/ROR/ASR/ASL/CLR/TST and D shifts.
- CPU12 right-shift/rotate V=N xor C, with complete CCR/operand expectations.
- INX/DEX/INY/DEY update only Z; ANDCC/ORCC retain the software X-mask limit.
- TFR/EXG/SEX and assembler aliases:196 normal postbytes, signed/fixed extensions,
  A/B/D overlap and CCR X restriction;60 factory TMP2/TMP3 forms refuse visibly.
- TAB/TBA preserve C/H/other flags and update N/Z/V.
- ABA/SBA/CBA use native byte arithmetic and independent H/N/Z/V/C expectations.
- DAA covers the nine documented rows; undefined V retention is explicit policy.
- Unqualified DAA states report original PC/A/C/H without retirement or CPU mutation.
- ABX/ABY retain flags through the existing LEAX B,X / LEAY B,Y aliases.
- MUL/EMUL/EMULS and IDIV/IDIVS/EDIV/EDIVS/FDIV use native host arithmetic,
  defined product/quotient/remainder flags and guarded zero/guest-overflow paths.
- Signed32 EDIVS uses host64 division; documented indeterminate fields are
  checked separately as core policy, without a silicon-equivalence claim.
- MOVB/MOVW all six source/destination combinations and all 236 single-postbyte
  index forms, sequential shared-base updates and unchanged CCR.
- Captured source values survive overlapping big-endian/wrapping word writes;
  real bus failures retain effects and defer CPU changes without a host frame.
- BSET/BCLR/BRSET/BRCLR direct/extended/all 248 nonindirect indexed forms.
- Complete address/mask/relative tails, read-only bit branches with unchanged
  CCR, native byte modifications and precise external phase faults.
- Six-byte captured inputs and complete raw byte/length native-cache keys.
- DBEQ/DBNE, IBEQ/IBNE, TBEQ/TBNE for A/B/D/X/Y/SP with unchanged CCR,
  signed9 offsets, ignored bit3 aliases and explicit undocumented refusals.
- Indexed/extended byte NEG/COM/INC/DEC/LSR/ROL/ROR/ASR/ASL/CLR/TST.
- Write-only CLR/read-only TST and native RAM RMW; external effects with staged
  flags/index/PC and precise pointer/read/write refusal without replay.
- Direct/extended byte load/ALU/store instructions, preserving all other registers.
- Immediate/direct/extended LDD/LDX/LDY/LDS, CPD/CPX/CPY/CPS, ADDD/SUBD.
- Direct/extended STD/STX/STY/STS, correct word NZVC and unchanged H.
- Big-endian known-RAM word reads/writes, including ffff-to-zero wrapping.
- Explicit logical wide callbacks; unknown wide accesses never guess byte semantics.
- Indexed byte/word load/ALU/store: all 256 postbytes, X/Y/SP/PC,
  signed 5-/9-bit and wrapping 16-bit constants, unsigned A/B/D and indirect pointers.
- X/Y/SP pre/post changes -8..-1 or 1..8, including source/destination overlap.
- LEAX/LEAY/LEAS: all 248 legal postbytes, preserve CCR and perform no data access.
- Complete captured-byte/length cache keys; ISA decode only on a cache miss.
- One explicit known RAM window with direct native byte/word/pointer access.
- Real external read/write callbacks, precise fault context and no automatic replay.
- Recursive execution and state/cache mutations are refused during callbacks.
- BRA/BRN and all short/long unsigned/signed conditional branches.
- Extended and all indexed JMP forms, including actual indirect pointer accesses.
- Direct/extended/indexed JSR, relative BSR and RTS with real big-endian return stacks.
- Byte/word PSH/PUL for A/B/CCR/D/X/Y; PULC cannot raise an initially clear X mask.
- Indirect calls retain their actual target across overlapping stack writes and bus faults.
- Native N/Z/V/C/H effects where specified; other CCR bits and registers retained.
- Captured-byte cache keys, bounded entry count and explicit cache invalidation.
- W^X code pages and a typed assembly bridge into generated code.
- Explicit unsupported input/ISA/host faults with original PC/opcode; no retirement.

The initial arithmetic/short-branch test enumerates every A/B value and immediate
operand for all 16 arithmetic/load/logic opcodes at three initial CCR values,
plus all 16 short conditions, every CCR byte and five displacements. It checks complete
register state, PC wrap, cache-clear/NOP and no-effect refusals. No manufacturer
program is used. This scope is distinct from an independently booting processor.

Open requirements:
- The remaining ISA and its addressing/control/stack forms, factory temporaries.
- Original M68HC12 move-queue PC corrections; current moves use HCS12 semantics.
- Additional memory-window types and multi-byte/per-instruction access boundaries.
- Native regions, executable mapping/invalidation contracts and event/timing budgets.
- Pending-source priorities/arbitration during run(), post-RTI tail chaining,
  SWI/trap/banked ISA and board timing, including chip-specific STOP wake sources.
- Persistent checkpoint encoding and joint CPU/memory/board/peripheral snapshots.
- Recognition timing for CCR-destination transfers beyond ANDCC/TAP transitions.
- Integration and state ownership with blofeld-emu; no emulator dependency pin yet.
- Real firmware startup, actual instrument behavior and whole-emulator throughput.
- Other host architectures, extensive sanitizer matrices and broader regression.

The separate SLEIGH comparison differs for 5-bit JSR0,SP versus equivalent
9/16-bit forms. CPU12 uses uniform pre-stack indexed address rules; this corner
remains physically unmeasured. stack.txt records the distinction.
