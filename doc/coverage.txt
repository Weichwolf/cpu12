CPU12 coverage — incomplete

Current public API: Core(Memory, Io*, Options), run_instruction(captured_bytes).
Borrowed byte views provide unified/window/external layouts; native cache bounds
are checked at construction. Captured execution still delegates fetching and
board time to its owner.

Initial native implementation on x86-64/Linux:
- Captured NOP.
- Immediate LDAA/B, ADDA/B, SUBA/B, CMPA/B, ANDA/B, ORAA/B, EORA/B, BITA/B.
- Direct/extended byte load/ALU/store instructions, preserving all other registers.
- Immediate/direct/extended LDD/LDX/LDY/LDS, CPD/CPX/CPY/CPS, ADDD/SUBD.
- Direct/extended STD/STX/STY/STS, correct word NZVC and unchanged H.
- Big-endian known-RAM word reads/writes, including ffff-to-zero wrapping.
- Explicit logical wide callbacks; unknown wide accesses never guess byte semantics.
- One explicit known RAM window with direct native byte access.
- Real external read/write callbacks, precise fault context and no automatic replay.
- Recursive execution and state/cache mutations are refused during callbacks.
- BRA/BRN and all short unsigned/signed conditional branches.
- Native N/Z/V/C/H effects where specified; other CCR bits and registers retained.
- Captured-byte cache keys, bounded entry count and explicit cache invalidation.
- W^X code pages and a typed assembly bridge into generated code.
- Explicit unsupported input/ISA/host faults with original PC/opcode; no retirement.

The independent directed test enumerates every A/B value and immediate operand
for all 16 arithmetic/load/logic opcodes at three initial CCR values, plus all 16
branch conditions, every CCR byte and five displacements. It checks complete
register state, PC wrap, cache-clear/NOP and no-effect refusals. No manufacturer
program is used. This scope is distinct from an independently booting processor.

Open requirements:
- The remaining ISA and indexed/other addressing forms.
- Additional memory-window types and multi-byte/per-instruction access boundaries.
- Native regions, fetch ownership/code invalidation and event/timing budgets.
- Reset, interrupt priorities/entry/return, wait/stop and complete checkpoints.
- Integration and state ownership with blofeld-emu; no emulator dependency pin yet.
- Real firmware startup, actual instrument behavior and whole-emulator throughput.
- Other host architectures, extensive sanitizer matrices and broader regression.

No native throughput or real-time claim is made from correctness test duration.
Broad QA is deferred until original Blofeld firmware runs in real time, as the
user requested. No fuzzing was run. The initial c86888a qualification is retained
in native-reference.json. Current API qualification is in
memory-api-reference.json, including all four coherently rebuilt native

Historical byte integration is in
